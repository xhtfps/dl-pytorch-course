## 1. 项目背景

- 语言模型是什么：给定前 n 个字，预测第 n+1 个字
- 为什么用歌词做教学：数据小（5.9 万字符）、现象直观、可玩性强
- 技术栈：PyTorch + LSTM + jieba + pypinyin

## 2. 环境搭建（含踩坑）

- conda 环境、torch GPU 版安装
- 坑 1：系统 python 没装 torch → 必须用 conda 环境显式调用
- 坑 2：PowerShell 下 jieba 的 pkg_resources warning 会把 exit code 标成 1（非真失败）

## 3. 数据获取与清洗（`06_数据集优化_歌词清洗.py`）

- 数据集：周杰伦 10 张专辑歌词（公开版）
- 清洗 4 步：opencc 繁转简 → 删英文/数字 → 过滤非中文行 → 去行首尾标点
- 效果：词表 2583 → 2354，生成不再出现繁体/英文乱入
- 数据洞察：为什么清洗能降 loss（1.76 → 1.36）

## 4. 结构化数据：副歌标记（`08_数据增强_副歌标记.py`）

- 动机：让模型学会"歌"的结构，而不是纯文字流
- 方法：检测重复行块（副歌重复 6-8 次）→ 首次出现处插 `<副歌>` 标记
- 实现细节：标记用私有区字符 `\ue000`（1 个 token），避免被 jieba 切开
- 效果：生成自动带"主歌 4 行 + 副歌 4 行"骨架

## 5. 词级 vs 字符级：数据密度的物理定律

- 关键实验数据（本项目的核心洞察）：
  | 方案 | 词表 | 语料 | 平均出现次数 | val loss |
  |---|---|---|---|---|
  | 词级 | 5520 | 3.4 万词 | 6 次 | 7.02（语序碎）|
  | 字符级 | 2355 | 5.9 万字符 | 25 次 | 3.44（流畅）|
- 结论：小语料必须用字符级，词太稀疏模型学不会语序

## 6. 模型搭建（逐层讲）

```python
self.embedding = nn.Embedding(char_count, 128)   # 字符ID → 128维向量
self.lstm = nn.LSTM(128, 512, 2, batch_first=True, dropout=0.3)
self.fc = nn.Linear(512, char_count)             # 记忆 → 全字符表分数
```

- 每层的数据形状变化：[B,64] → [B,64,128] → [B,64,512] → [B,64,2355]
- 参数量：4.93M，为什么这么小（权重共享）

## 7. 训练优化（`09` 的 train 函数）

- 验证集早停：90/10 划分，连续 15 轮不降即停（自动选最优轮）
- ReduceLROnPlateau：验证 loss 5 轮不降 → lr 减半
- 梯度裁剪 clip_grad_norm_(5)：防 RNN 梯度爆炸
- 对比：固定 300 轮 → 过拟合生成乱码（loss 0.07 的陷阱）

## 8. 生成技巧：采样控制（重点，全是踩坑换来的）

1. 温度采样：temperature=0.7（<1 保守 >1 发散）
2. top-k：只从概率前 8 个里抽 → 避免低概率乱码
3. 单字重复惩罚：已出现字 logits 打折（防"我我我我"）
4. 双字序列惩罚：已出现的 (前字,后字) 对打折 → 治"儿啦呜"交替循环
5. 合法字符掩码：只允许汉字+中文标点，排除英文/符号
6. 风格字偏置 +0.3：85 个周氏意象字加 logits → 用词偏向杰伦
   - 坑：偏置 1.0 会自我强化成"默默默默默"，必须低偏置

## 9. 韵律引擎（pypinyin 韵脚）

- 构建韵脚词典：每行末字 → 韵母 → 分组
- 生成策略：第 2 行定"主韵"，第 4/6/8 行行尾强制从主韵组采样
- 效果：ABAB 押韵 100% 命中

## 10. 踩坑合集（读者最爱看的部分）

| 坑 | 现象 | 根因 | 解法 |
|---|---|---|---|
| 标记被切开 | KeyError '<' | jieba 切 `<副歌>` | 用私有区字符单 token |
| 过拟合 | 300 轮 loss 0.07 乱码 | 背死语料 | 早停 + 验证集 |
| 风格自强化 | "默默默"刷屏 | 偏置 1.0 太高 | 降到 0.3 |
| 交替循环 | "儿啦呜儿啦呜" | 单字惩罚无效 | 双字序列惩罚 |
| 词级语序碎 | "要了豆腐" | 词太稀疏 | 换字符级 |

## 11. 效果对比与总结

- 全流程对比表：04 词级 → 05 字符级 → 07 词级升级(失败) → 09 最终版
- 方法论总结：数据密度 > 模型大小；采样控制 > 无限训练
